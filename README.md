🏨 OmniBooking CRM Inteligente
OmniBooking CRM es un ecosistema avanzado de gestión, cualificación y análisis estratégico de leads diseñado exclusivamente para el sector de la hospitalidad (hoteles, resorts y alquileres vacacionales).

A diferencia de los CRMs genéricos, esta plataforma transforma los datos operativos de los hoteles (tamaño de la propiedad, volumen de reservas y software actual) en diagnósticos comerciales de alto impacto y planes de acción automatizados, optimizando drásticamente la tasa de cierre de ventas B2B.

✨ Características Principales
1. Centro de Mando 360° (Dashboard)
Visualización Dinámica: Control total de las solicitudes entrantes ordenadas de forma cronológica.

Cualificación en la Captura: Registro estructurado de datos críticos de negocio: tamaño del establecimiento (habitaciones), volumen transaccional mensual, ecosistema tecnológico actual (PMS) y su punto de dolor crítico.

2. Buscador Semántico (Smart Prompt)
Interfaz intuitiva estilo IA que rompe con los filtros tradicionales rígidos.

Permite realizar consultas libres combinando múltiples criterios de negocio (por ejemplo: "hoteles con Cloudbeds que sufren overbooking" o "propietarios con problemas de horario"), filtrando toda la base de datos de manera multidimensional e instantánea.

3. Módulo de Análisis Avanzado por Objetivo
Diagnósticos a Medida: Generación automática de reportes corporativos profundos basados estrictamente en el desafío específico de cada establecimiento.

Planes de Acción Técnicos: Hoja de ruta sugerida para que el asesor comercial plantee la solución óptima (automatización 24/7, middlewares de sincronización, etc.).

Proyección Financiera (ROI): Cálculos de retorno de inversión estimados según el volumen del hotel, dotando al equipo de ventas de argumentos económicos sólidos antes de cada llamada.

🛠️ Tecnologías Utilizadas
La aplicación está construida sobre un stack moderno que prioriza la velocidad de carga, la robustez de los datos y una experiencia de usuario fluida:

Framework: Next.js (App Router) - Combinación óptima de Server y Client Components.

Lenguaje: TypeScript - Tipado estricto para un flujo de datos seguro.

Base de Datos: SQLite (better-sqlite3) - Motor local ultrarrápido configurado en modo WAL (Write-Ahead Logging) para una concurrencia eficiente.

Estilos: Tailwind CSS - Interfaz premium en modo oscuro optimizada para la visualización de datos analíticos.

nstalación y Puesta en Marcha
Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1. Clonar el repositorio e instalar dependencias
Bash:
"npm install"
2. Ejecutar el servidor de desarrollo
Bash:
"npm run dev"
3. Acceso a la aplicación
Abre tu navegador e ingresa a la siguiente dirección para interactuar con el panel de administración inteligente:

Dashboard Admin: http://localhost:3000/admin

💡 Nota sobre los datos: La aplicación cuenta con un Autoseeder integrado en la capa de datos. La primera vez que accedas al panel, si la base de datos está vacía, el sistema generará automáticamente 20 registros hoteleros altamente realistas con diferentes desafíos y tamaños de hotel para que puedas probar el potencial de las herramientas analíticas desde el primer segundo.
